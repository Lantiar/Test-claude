# Unknown ATS

No playbook for this host. Work from what is on the page.

Fill only what the profile answers. If a required field has no answer in the profile,
leave it blank and report it as unanswered rather than inventing a value — an invented
answer on a real application is worse than a queued one.

Stop and report rather than working around: CAPTCHAs, sign-in or account-creation
screens, and email or SMS verification steps.
