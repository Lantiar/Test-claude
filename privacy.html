jobfeed — privacy policy

Last updated 10 September 2026

jobfeed is a personal tool used by one person, its author, to track internship applications and to write to recruiters at the companies he has applied to. It is not offered as a service to anyone else and has no other users.

What it accesses

The application requests two Google account scopes, both against the author's own Gmail account:

  • gmail.send — to send the author's own application follow-up emails from his own address.
  • gmail.readonly — to read replies and delivery failures for those messages, so that a follow-up is not sent to somebody who has already answered and so that an address which bounced is never written to again.

What it stores, and where

All data is held in storage controlled by the author — an Upstash Redis database and a GitHub repository, both private to him:

  • Public job postings collected from public sources.
  • Which postings he has applied to, and what stage each application is at.
  • For recruiters at those companies: name, job title, public LinkedIn profile URL and work email address, obtained from a commercial data provider.
  • The emails he has sent, when they were sent, and whether each one was answered or bounced.

Message contents are read only to classify a reply as an answer, an automatic reply, or a delivery failure. Nothing from the mailbox is stored beyond what is described above.

What it does not do

  • No data is sold, rented, or shared for advertising.
  • No data is transferred to anyone other than the service providers the tool calls to do its work — Apify for recruiter search and address verification, and OpenAI to check the grammar of the author's own drafts before he sends them.
  • No Google user data is used to develop, improve, or train any generalised or non-personalised model.
  • There is no advertising, no analytics, and no tracking of any kind.

Limited use

jobfeed's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Data is kept only while it is useful to the author and can be deleted by him at any time. Access can be withdrawn at any point from the Google account permissions page, which immediately revokes the token the tool uses.
